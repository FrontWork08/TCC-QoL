> Um aplicativo web completo para acompanhamento de saúde física e emocional, com inteligência artificial integrada.

---

## 📱 Sobre o Projeto

O **VitaIA** é um assistente pessoal de qualidade de vida que ajuda você a monitorar e melhorar sua saúde diária. Com uma interface amigável e recursos de IA, o aplicativo oferece:

- ✅ Registro de humor diário
- ✅ Controle de hidratação
- ✅ Acompanhamento nutricional (proteínas, carboidratos, gorduras)
- ✅ Banco de dados de alimentos
- ✅ Registro de exercícios físicos
- ✅ Planos personalizados gerados por IA
- ✅ Chat de apoio emocional
- ✅ TeleSaúde com profissionais
- ✅ Laboratório de funcionalidades IA

---

## 🚀 Funcionalidades

### 📊 Home
- Registro de humor (5 níveis)
- Controle de consumo de água
- Acompanhamento nutricional
- Insights motivacionais com IA
- Botão de ajuda imediata

### 📈 Progresso
- Estatísticas diárias
- Histórico de hábitos

### 🎯 Plano Personalizado

### 🧪 Laboratórios IA
- **Visão Pro** - Análise de alimentos por foto (em breve)

- **Deep Think** - Consultas aprofundadas

### 🩺 TeleSaúde
- Agendamento de consultas
- Chat com profissionais
- Lista de profissionais disponíveis
- Sistema de avaliação

## 📦 Como Executar

### Pré-requisitos
- Navegador moderno (Chrome, Edge, Firefox)
- Conexão com internet (para funcionalidades IA)

### Passo a passo

1. **Baixe os arquivos**

index.html/
style.css/
script.js

2. **Coloque na mesma pasta**

3. **Abra o arquivo `index.html`** no navegador

4. **Crie uma conta** (nome, email, senha)

5. **Comece a usar!** 🎉

## 🔐 Armazenamento de Dados

- Todos os dados são salvos localmente no **localStorage** do navegador
- Nenhuma informação é enviada para servidores externos (exceto API da Groq para IA)
- Os dados incluem:
  - Usuários cadastrados
  - Histórico de humor
  - Consumo de água
  - Registros nutricionais
  - Exercícios
  - Consultas agendadas

---

## 🤖 API Utilizada

O VitaIA utiliza a **API da Groq** com o modelo **Llama 3 70B** para:
- Gerar insights motivacionais
- Criar planos personalizados
- Responder no chat de ajuda
- Orientação no TeleSaúde

> **Nota:** A chave API já está inclusa no código. Se parar de funcionar, substitua pela sua em `script.js`.
